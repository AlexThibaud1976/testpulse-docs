TP-DOC — Kit de la boutique de démonstration / Demo shop kit

FRANÇAIS
1. Décompressez le ZIP (clic droit > Extraire tout sous Windows).
2. Ouvrez boutique-demo.html dans votre navigateur.
3. Ajoutez un produit au panier : 20 EUR.
4. Validez avec une adresse vide : la commande fictive est acceptée.
   Ce défaut est volontaire et sert à l'atelier TestPulse.
5. Pour recommencer, cliquez sur Recommencer.

Le fichier tp-doc-test-cases-fr.csv est facultatif : il sert à préparer
trois cas dans Azure Test Plans. Adaptez les champs exigés par votre
processus. Les identifiants sont vides : chaque nouvel import crée
de nouveaux work items. Importer les cas ne les exécute pas.

La boutique fonctionne hors ligne, sans installation, serveur, paiement,
stockage persistant ni envoi de données. Utilisez des données fictives.
L'accès à Azure DevOps pour les ateliers nécessite une connexion.
Guide : https://docs.atconseil.info/fr/tutorials/demo-project

ENGLISH
1. Extract the ZIP (right-click > Extract All on Windows).
2. Open boutique-demo.html in your browser and select English.
3. Add one item to the cart: EUR 20.
4. Submit with an empty address: the fictional order is accepted.
   This defect is intentional and supports the TestPulse workshop.
5. To start again, select Reset exercise.

The optional tp-doc-test-cases-fr.csv prepares three cases in Azure
Test Plans. Adapt fields required by your process. IDs are empty:
each new import creates new work items. Importing does not run tests.
Case names remain French in both documentation languages.

The shop works offline, without installation, a server, payment,
persistent storage or data transmission. Use fictional data only.
Azure DevOps access for the workshops requires a connection.
Guide: https://docs.atconseil.info/en/tutorials/demo-project
