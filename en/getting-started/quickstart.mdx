This path summarises the essential actions. For practice data and detailed checkpoints, follow [Your first report, from plan to PDF](/en/tutorials/first-report).

## Before you start

You need to be able to open TestPulse and read a plan containing test cases. Execution results are needed to see more than an unexecuted campaign. Also prepare the information your project requests: title, environment, and visible required business fields.

<Frame caption="The Report tab on arrival: selection on the left, the report panel still empty on the right.">
  <img src="/images/en/quickstart-01-report.png" alt="TestPulse Report tab before generation, showing the selection form and empty panel" />
</Frame>

<Steps>
  <Step title="Open TestPulse" icon="rocket">
    In your project, go to **Test Plans** and open **TestPulse**, then the **Report** tab. If the hub is missing, check the [installation](/en/getting-started/installation).
  </Step>
  <Step title="Choose the scope" icon="list">
    Select a plan, then check the included suites. Keep to one plan for this first attempt.

    **You should see:** the selected plan's name and suites to include. Selecting a plan does not download a document.
  </Step>
  <Step title="Complete the form" icon="pen">
    Fill in the required fields shown: for example, the title **First campaign report** and the environment actually tested. Other required fields depend on your configuration; do not assume they are prefilled.

    If a value is missing or has the wrong format, the validation message identifies the field to fix.
  </Step>
  <Step title="Generate and read the report" icon="eye">
    Select **Generate** and wait for loading to finish. The report appears **on screen**.

    **You should see:** the correct title, scope and test results. Check these before exporting. Generation also saves a snapshot in your personal history; it does not modify test results.
  </Step>
  <Step title="Export the PDF" icon="file-output">
    In the generated report's export toolbar, select **PDF**. Open the downloaded file and compare its title, scope and counters with the displayed report.

    The other buttons produce **Word, Excel, HTML or PowerPoint**. If PDF is hidden, check [export button visibility](/en/exports/button-visibility).
  </Step>
</Steps>

## What you just produced

You now have a report viewable in TestPulse, a personal history snapshot and a local PDF. Its content reflects the selected suites, available data and report options at generation time. Sharing the file or [sharing the report to the project](/en/collaboration/history) is a separate action.
